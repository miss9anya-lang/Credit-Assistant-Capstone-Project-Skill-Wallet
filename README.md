# 💳 Credit Assistant

> Understand your credit. Improve your finances. Build better financial habits.

**Credit Assistant** is an AI-powered financial wellness platform designed for users in India. It helps users understand their credit health, track financial metrics, monitor loans, and receive personalized AI-powered recommendations.

## 🚀 Live Demo

👉 **[Try Credit Assistant](https://credit-assistant-pla-up0a.bolt.host)**

## ✨ Features

- 📊 Credit Score Tracking
- 💰 Financial Health Analysis
- 📈 Credit Score Progress Charts
- 💳 Credit Utilization Analysis
- 📉 Debt-to-Income Ratio Calculation
- 🏦 Active Loan Monitoring
- 🤖 AI Financial Advisor
- 🎯 Personalized 5-Step Improvement Plan
- 📄 Financial Report Generation
- 🔐 Secure User Authentication

## 🛠️ Tech Stack

- React.js
- FastAPI
- Python
- SQLAlchemy
- SQLite
- Recharts
- Pydantic
- Google Gemini AI

## 🎯 Purpose

Credit Assistant aims to make financial information simple, understandable, and actionable for students, young professionals, and individuals who want to better understand and improve their financial health.
